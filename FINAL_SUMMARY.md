## 🎨 Design Features

### Glass UI
- Clear backdrop-blur (24px, not milky)
- 3D glow effect (blue `rgba(100, 200, 255, ...)`)
- Multiple shadow layers for depth
- Smooth transitions (0.6s cubic-bezier)

### 3D Effects
- Hover lift: -12px translation
- Hover tilt: 2-degree 3D rotation
- Glow pulse on hover
- Smooth scale feedback on click

### Typography
- **Stretched Headlines**: Space Grotesk (up to 6rem)
- **Premium Body**: Satoshi font
- **UI Text**: Inter (clean, professional)
- **Responsive**: Clamp for all sizes

### Animations
- **Page Load**: 1.2s loader with dots
- **Cascade**: Hero elements stagger in
- **Scroll Reveal**: Sections fade in on view
- **Parallax**: Background scrolls slowly
- **Hover**: Panel lifts with glow

### Spacing
- **Sections**: 8rem padding (py-32)
- **Panels**: Large border-radius (32px)
- **Padding**: 10-16rem inside panels
- **Gap**: 8-12rem between cards
